# 图片资源目录

请将以下图片放置在此目录中：

## 必需的图片

| 文件名 | 用途 | 建议尺寸 |
|--------|------|----------|
| `hero-banner.jpg` | 首页全屏背景图（产品介绍大图） | 1920x1080 或更大 |
| `video-cover.jpg` | 视频区域封面图 | 1280x720 (16:9) |
| `scenario-study.jpg` | 使用场景 - 书房/学习 | 800x450 (16:9) |
| `scenario-library.jpg` | 使用场景 - 图书馆 | 800x450 (16:9) |
| `scenario-garden.jpg` | 使用场景 - 花园/户外 | 800x450 (16:9) |
| `scenario-cafe.jpg` | 使用场景 - 咖啡馆 | 800x450 (16:9) |
| `security.jpg` | 数据安全信息图 | 1200x675 (16:9) |

## 图片要求

- 格式：JPG 或 PNG
- 质量：建议压缩后的 web 优化图片
- 风格：高端、简约、阅读相关的场景

## Hero 背景图说明

`hero-banner.jpg` 是首页第一屏的全屏背景图：
- 文字会叠加在左下角
- 会有从左到右的暗色渐变遮罩
- 建议使用产品实拍图或高质量渲染图
- 参考风格：remarkable 官网首页
